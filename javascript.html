JavaScript

JavaScript é a linguagem responsável por dar comportamento e interatividade ás pagínas web, permitindo responder a ação do usuário(como cliques e digitação), manipular o conteúdo do HTML, em tempo real e se comunicar com servidores;

Em resumo, equanto HTML estrutura e CSS estiliza, o javaScript fas a pagína "funcionar"
